## How each solution is written

Every file starts with a short header:

```python
# Problem: Find the GCD of two numbers
# Approach: Euclidean algorithm
# Time: O(log(min(a, b)))  Space: O(1)
```

Where it makes sense, I include more than one approach (brute force first, then the
optimized one) and compare them.

## Topics covered

- **Basic Programs:** loops, conditions, number problems, patterns
- **Arrays:** traversal, prefix sums, Kadane's algorithm, matrices
- **Strings:** palindromes, anagrams, compression, substrings
- **Sorting & Searching:** bubble, merge and quick sort, binary search and its variations
- **Stack & Queue:** parentheses, monotonic stack, deque
- **Recursion:** subsets, permutations, backtracking
- **Two Pointers:** sorted arrays, 3Sum, container with most water
- **Sliding Window:** fixed and variable windows, substring problems

## How to run a solution

```bash
python 01_basic/day_01_hello_world.py
```

Requires Python 3.8 or higher. No extra libraries are needed.
